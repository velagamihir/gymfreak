# 🏋️‍♂️ HostelFit Pro (GymFreak) — 91kg Transformation Coach & Workout Hub

A modern, responsive React.js web application engineered specifically for a **21-year-old male (91 kg)** looking to achieve body recomposition (drop body fat down to 75 kg while building solid muscle) using the exact equipment in a hostel gym and optimizing Indian hostel mess nutrition.

---

## 🎯 Profile & Transformation Goals

- **Age:** 21 Years Old
- **Current Weight:** 91 kg
- **Target Weight:** 75 kg (Athletic, lean, and muscular)
- **Daily Deficit Target:** **1,950 kcal / day** (~600 kcal deficit)
- **Daily Protein Target:** **140g / day** (Essential to preserve & build muscle during fat loss)
- **Daily Water Target:** **3.5 Liters / day**

## 🏋️‍♂️ Gym Equipment Available & Calibrated Routine

1. **Straight Barbell + Weight Plates** (Heavy compound lifts: Bench/Floor Press, Squats, Deadlifts, OHP, Rows)

5. **Stationary Cycle (Legs only)** (Zone 2 steady-state & post-leg day lactic acid flush)
6. **Treadmill** (12-3-30 high-incline fat oxidation walking — zero knee impact for 91kg bodyweight)

## 🍛 Indian Hostel Mess Diet & Nutrition Blueprint

### 1. Meal Schedule & Portion Control
- **Breakfast Rotation:** 3 Idlis + Sambar / 1 bowl Poha with peanuts / 1.5 Parathas with Curd / Bread Omelette (300-380 kcal budget).
- **Daily Lunch (Rice + Dal + Curry):** 
  - **The Hostel Half-Plate Rule:** 1/2 plate raw cucumber/salad & sabzi, 1/4th plate rice (1 standard cup / 150g), 2 deep bowls thick dal (ask staff to stir from bottom).
- **Daily Dinner (3 Rotis + Curry + Sambar Rice + Curd Rice):** 
  - 3 dry phulkas/rotis + 1 bowl sabzi + 1 small bowl curd rice (probiotic gut health & restful sleep).

### 2. Special Meal Days
- **🥚 Tuesday Special (1 Boiled Egg):** The mess gives **1 boiled egg** (+6g protein, 70 kcal). Pair with room hacks (40g soya chunks or Amul lassi) to easily cover your dinner protein requirement.
- **🍳 Friday Special (Egg Fried Rice):** 1.5 cups portion cap as a post-workout carb reload (avoid oily Manchurian/gravies).

### 3. 6 Zero-Cooking Hostel Room Protein Hacks (Hit 140g Daily)
1. **Electric Kettle Soya Chunks Soak:** 40g soya chunks in boiling water for 5 mins + chaat masala = **21g Protein (Cost: ₹8)**.
2. **Bhuna Chana (Roasted Bengal Gram):** 50g jar snack = **10g Protein + 13g Fiber**.
3. **Amul High-Protein Lassi / Buttermilk:** Canteen tetra pack = **15g Protein (Cost: ₹25, zero sugar)**.
4. **Hostel Gate Boiled Eggs:** 3 whites + 1 whole from tea stall on non-egg days = **16g Protein (Cost: ₹20)**.
5. **Desi Sattu Energy Drink:** 3 spoons sattu in cold water with lemon & black salt = **11g Protein**.
6. **Whey Protein (Optional):** 1 scoop in shaker with water = **24g Pure Isolate Protein**.

## ✨ Application Features

- **🎬 Exercise Video Vault:** Pop-up modal with embedded YouTube video tutorials (*Jeff Nippard, Squat University, Alan Thrall, Athlean-X*) with form cues and joint safety tips.
- **⏱️ Live Interactive Workout Mode:** Set checkboxes, weight (kg) and rep inputs, and an animated rest timer (30s/45s/60s/90s/120s) with Web Audio sound effects.
- **⚡ 1-Tap Hostel Macro Tracker:** Instant logging for mess staples with real-time calorie deficit & 140g protein progress bars.
- **🚴‍♂️ Cardio Hub & Live Tabata Timer:** 8-round interactive countdown clock for the Dual-Action Air Bike.
- **📈 91kg → 75kg Road to Transformation:** Trajectory roadmap, Sunday weigh-in logger (saved to `localStorage`), BMI calculator, and a 14-cup (3.5L) water tracker.
- **🌓 Dark / Light Mode Support:** Sleek glassmorphic theme with neon accents and mobile bottom navigation.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/velagamihir/gymfreak.git
cd gymfreak

# Install dependencies
npm install

# Start the local development server
npm run dev
```

The app will start at `http://localhost:5173/`.

### Production Build
```bash
npm run build
```
